Support

Updated October 12, 2026

Need help with The Bridge Room? Start with the steps below or send an email. The app supports solo bridge practice and nearby games with other iPhones and iPads.

Contact support
artful.skates_4j@icloud.com

Include your device model, iOS or iPadOS version, app version and a short description of what happened. A screenshot and steps to reproduce help. For a bidding or play question, include the auction and an exported deal if possible. Please leave out information you do not want to share.

Play offline

The native iPhone and iPad app includes the solo game and bots. Tap Play solo; no sign-in or internet connection is required. External reference links and sending support email need a connection. Installing or updating the app through Apple is separate from offline gameplay.

Start a nearby table

  1. Install the same app version on each device. Keep Wi-Fi enabled and allow Local Network access when asked.
  2. On the host device, tap Play nearby, enter a name, choose a host seat and tap Host table.
  3. The host gives each guest the four-digit PIN for the desired seat.
  4. On each guest device, tap Find a table, select the host and enter the PIN. Include leading zeroes. Tap Join table.
  5. The host taps Start. Empty seats are filled by bots.

A shared Wi-Fi router and internet connection are not required. Keep the devices nearby and the apps open during play. Only the host can enable Training mode for nearby hints and undo.

If a nearby table does not appear

Check that Wi-Fi is on and the devices use the same app version. In iOS Settings, open Privacy & Security → Local Network and allow The Bridge Room. Return to the app and choose Find a table again. If a PIN is rejected, confirm the seat PIN with the host and enter all four digits.

Interruptions and saved progress

Backgrounding a player pauses the nearby table. Return to the app to reconnect. The host must stay available: leaving the table or force-quitting the host ends that game. Current hands, undo history and session scores are held in memory and are not saved for recovery after the app closes.

Saved solo deals, preferences and your nearby player name remain on the device. The deal library does not automatically sync between devices.

Save or share a deal

In solo mode, open Menu → Deal library. Save a deal to play it later. Tap its share icon to send a deal file through Messages or another app, or save it to Files. Export library makes a backup; Import library accepts a shared deal or a library backup. Keep a backup before removing the app or clearing its data.

Understand hints

Press and hold a bidding button to see the call’s meaning without bidding. Card hints estimate outcomes from possible hidden hands and a bounded search. They can help compare choices, but they are not guarantees of the best play. Report surprising advice with the deal, auction and earlier play so the position can be reproduced.

TestFlight feedback

If you installed a beta, you can also use Send Beta Feedback in TestFlight. The current testing instructions are shown with the build in TestFlight.
